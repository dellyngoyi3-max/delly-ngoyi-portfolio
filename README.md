# Portfolio de Delly Ngoyi

Portfolio personnel statique (HTML, CSS et JavaScript), accompagné des CV téléchargeables en français et en anglais.

## Prévisualisation locale

Depuis la racine du dépôt :

```bash
python3 -m http.server 8000
```

Ouvrir ensuite `http://localhost:8000`.

## Hébergement

Le site ne nécessite aucune étape de compilation. Pour l’héberger sur Firebase Hosting, configure la racine de ce dépôt comme répertoire public afin de conserver `index.html`, `assets/` et `cv/`. Les PDF dans `cv/` sont destinés au téléchargement public depuis le portfolio.
